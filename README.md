## Experience

MINATO is a visual story told through motion, light, particles, and scroll. The page moves from stillness to the Yellow Flash, turning Minato's speed and precision into an interactive sequence.

- Scroll-scrubbed opening frames that awaken his gaze
- Interactive particle portrait that responds to the cursor
- Full-bleed speed sequence built from local frame animation
- Rasengan sequence that tracks horizontal movement
- Atmospheric canvas effects, thunder, grain, and ghost cursor motion
- Responsive layout with reduced-motion support
- Japanese and English typography for a cinematic editorial feel

## Run Locally

This is a static website with no build step or package installation required.

1. Clone the repository.
2. Open `index.html` in a modern browser, or serve the folder with any static web server.

For example, with Python installed:

```bash
python -m http.server 8000
```

Then open [http://localhost:8000](http://localhost:8000).

## Built With

- HTML5 and CSS3
- Modern vanilla JavaScript modules
- Three.js loaded through an import map
- Canvas rendering and local animation frame sequences
- Google Fonts: Shippori Mincho, Zen Kaku Gothic New, Anton, Space Grotesk, and JetBrains Mono

## Project Structure

```text
├── particle-object.js  # Interactive particle portrait
├── ghost-cursor.js     # Ghost cursor and legacy scene behavior

└── frames/             # Scroll animation frame sequences
```
